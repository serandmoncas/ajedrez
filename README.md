# Ajedrez

Entrenador diario de ajedrez en español (PWA): repaso espaciado de problemas, patrones,
aperturas y partidas famosas, en sesiones de hasta 30 minutos.

## Desarrollo

```bash
npm install
npm run dev
npm test
```
